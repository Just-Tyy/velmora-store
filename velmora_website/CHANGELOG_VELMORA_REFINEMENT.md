# VELMORA — Refinement Pass Changelog

## What changed
- Added five locally bundled WebP derivatives of the existing project photography and redirected key campaign, product, and detail image references to the optimized files.
- Added a bespoke, local SVG woven-texture asset and applied it as a restrained newsletter background treatment.
- Refined the Bag control with an oxblood background reveal, subtle lift, shadow, count-badge inversion, pressed feedback, and keyboard-focus styling.

## Still demo-only
- Product names, pricing, product attributes, and photography are illustrative and must be confirmed against real inventory.
- Bag state is stored in browser local storage; it is not an order system.
- No payment processing, shipping/tax calculation, stock reservation, customer accounts, or newsletter provider is connected.
- Canonical URLs and sitemap deployment values must be configured once the real domain is known.
