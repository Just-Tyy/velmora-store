VELMORA — Hybrid Premium Website (Content Audit Pass)

DEPLOY TO NETLIFY
1. Extract this ZIP.
2. Open the `velmora_website` folder (the folder containing index.html, styles.css, script.js, and netlify.toml).
3. Drag that folder into Netlify's manual deploy dropzone, or connect the folder's Git repository for repeatable deployments.
4. Test the published homepage, Collection, each product detail, mobile menu, active navigation states, product filters/sorting, add-to-cart flow, quantity controls, remove/clear cart, and 404 page.
5. The shared header now uses the supplied V/M monogram with the VELMORA wordmark consistently across all core pages. See `CONTENT_AUDIT_AND_LAUNCH_NOTES.md` for content corrections and launch blockers.

IMPORTANT
This is a high-fidelity front-end concept, not a live commerce backend. Sample USD prices are clearly labelled concept prices. Checkout and newsletter submission are intentionally non-operational and disclose that to visitors. Connect a real commerce platform and newsletter provider before taking orders or collecting email addresses.

Before production SEO launch: configure your domain, absolute canonical URLs, sitemap.xml, Search Console, analytics with an appropriate privacy notice, verified product details, and real business policies.
